# Reference: HTML Output Standards

Every HTML file generated by `/ui-implement` must meet ALL of these standards.

---

## 1. File Structure

```html
<!DOCTYPE html>
<html lang="[ar|en]" dir="[rtl|ltr]">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>[Page Title] | [Project Name]</title>
  <style>
    /* ALL CSS HERE — no external link tags */
  </style>
</head>
<body>
  <!-- SECTION: navbar -->
  <!-- SECTION: main-content -->
  <!-- SECTION: footer -->
  <!-- SECTION: nav-pill -->
  <script>
    /* ALL JS HERE — no external script tags */
  </script>
</body>
</html>
```

---

## 2. Self-Contained Requirement

| Rule | Allowed | Forbidden |
|------|---------|-----------|
| Stylesheets | `<style>` block in `<head>` | `<link rel="stylesheet">` to any URL |
| Scripts | `<script>` block at end of `<body>` | `<script src="">` to any URL |
| Fonts | CSS `@import` inside `<style>` for Google Fonts; base64 `@font-face` | `<link>` to Google Fonts CDN |
| Images | Inline SVG, CSS shapes, data URIs | `<img src="https://...">` |
| Icons | Inline SVG or Unicode characters | Icon font CDN (Font Awesome, etc.) |

---

## 3. Realistic Content

- **Never** use Lorem Ipsum
- Use content in the project's primary language (Arabic for Arabic-first projects)
- Course names: real-sounding training course names ("قيادة الفرق الفعّالة", "التفاوض الاحترافي")
- People names: culturally appropriate (Arabic: "أحمد محمد", "فاطمة العلي")
- Phone numbers: match the project's phone regex format
- Prices: use the correct currency (EGP, SAR) with realistic amounts
- Dates: use future dates in regional format
- Status labels: exact strings from the data model enums
- Table data: minimum 3–5 rows of realistic data

## 4. Responsive Layout

```css
/* Mobile first (320px+) — base styles */
.container { width: 100%; padding: 0 16px; }

/* Tablet (768px+) */
@media (min-width: 768px) {
  .container { max-width: 720px; margin: 0 auto; padding: 0 24px; }
  .grid-3 { display: grid; grid-template-columns: repeat(2, 1fr); gap: 24px; }
}

/* Desktop (1280px+) */
@media (min-width: 1280px) {
  .container { max-width: 1200px; }
  .grid-3 { grid-template-columns: repeat(3, 1fr); }
}
```

Rules:
- No fixed pixel widths on any container
- Images: `max-width: 100%; height: auto`
- Tables: wrap in `overflow-x: auto` div on mobile
- Minimum tap target: 44×44px for all clickable elements
- Body text: minimum 14px on mobile, 16px preferred

## 5. The 46 Impeccable Anti-Patterns (Do Not Use)

### Color
1. Purple-to-blue gradient as primary palette
2. Neon/electric accent colors on white backgrounds
3. Pastel color schemes for professional tools
4. Color as the only indicator of state — add icon or text too
5. Gray text on colored backgrounds (check contrast ratio)
6. Gradient text on headings (text-gradient CSS)
7. Busy repeating background patterns competing with foreground

### Typography
8. Inter font used by default without brand justification
9. Decorative/display fonts used for body text
10. More than 3 font weights in the same component
11. Mixed uppercase and lowercase within the same heading
12. Centered text in paragraphs longer than 1 line
13. Body text under 14px on any viewport

### Layout
14. Cards nested inside cards
15. Side-tab card borders (left-colored accent border)
16. Icon tiles stacked above every single feature heading
17. Numbered section markers in headings (01, 02, 03...)
18. Footer with more than 4 columns on desktop
19. Horizontal scrolling on any breakpoint
20. Cluttered layouts without breathing room (minimum 24px between sections)
21. Full-bleed hero with extreme dark overlay making text hard to read
22. Overuse of borders instead of spacing for element separation
23. Inconsistent spacing between visually similar elements

### Animation
24. Bounce or elastic CSS keyframe animations
25. Scroll hijacking / parallax that fights native scroll
26. Hover transitions over 400ms

### Interactive
27. Buttons with insufficient padding (minimum 12px vertical, 24px horizontal)
28. Buttons styled to look like links (and links styled like buttons)
29. Form inputs without associated `<label>` elements
30. Tap targets under 44×44px on mobile
31. Navigation without clearly visible active/current state
32. Dropdown menus with more than 10 items and no search
33. Tooltips that cover important content when triggered

### Hierarchy
34. Multiple primary CTAs competing on the same page (max 1 per viewport)
35. More than 3 badge/tag types per card
36. Competing box shadows on the same visual level
37. Flat design with zero visual hierarchy (no shadows, no depth, no contrast)

### Accessibility
38. Text contrast ratio below 4.5:1 (WCAG AA normal text)
39. Large text contrast below 3:1
40. Images without `alt` attributes
41. Interactive elements not reachable by keyboard (Tab key)

### Components
42. Modals wider than 90vw on mobile
43. Empty states with no guidance or CTA
44. Loading states as bare, unstyled spinners
45. Oversized border radius on cards (maximum 12px; maximum 8px on inputs)
46. Logo too small to read at normal display size

## 6. Color Contrast

| Text type | Minimum ratio | Check with |
|-----------|--------------|-----------|
| Normal text (< 18pt) | 4.5:1 | browser DevTools, contrast checker |
| Large text (≥ 18pt bold, ≥ 24pt normal) | 3:1 | |
| UI components and graphics | 3:1 | |

## 7. Typography Rules

- **Heading hierarchy**: `<h1>` → `<h2>` → `<h3>` — never skip levels
- **Line height**: headings 1.2–1.3, body 1.5–1.7
- **Letter spacing**: headings −0.02em to 0.01em, body 0 to 0.01em
- **Max line width**: 65–75 characters (approximately 650px at 16px)
- **Arabic-specific**: use `font-feature-settings: "kern" 1` for Arabic fonts

## 8. Interactive States (all required)

```css
.button:hover   { /* darken or lighten primary by 10% */ }
.button:focus   { outline: 2px solid var(--color-primary); outline-offset: 2px; }
.button:active  { transform: scale(0.98); }
.button:disabled{ opacity: 0.5; cursor: not-allowed; }

input:focus     { border-color: var(--color-primary); box-shadow: 0 0 0 3px rgba(..., 0.2); }
input:invalid   { border-color: var(--color-error); }

a:hover         { text-decoration: underline; }
a:focus         { outline: 2px solid var(--color-primary); outline-offset: 2px; }
```

---

## 9. Arabic RTL Requirements

- `<html dir="rtl" lang="ar">` on every Arabic-first page
- CSS logical properties throughout:
  - `margin-inline-start` instead of `margin-left`
  - `padding-inline-end` instead of `padding-right`
  - `border-inline-start` instead of `border-left`
- Arabic font load inside `<style>`:
  ```css
  @import url('https://fonts.googleapis.com/css2?family=Cairo:wght@400;600;700&display=swap');
  ```
- Admin sections: `<div dir="ltr">` wrapper
- Icons that imply direction (arrows, chevrons) must be mirrored via `transform: scaleX(-1)`

## 10. Navigation Pill (required on every page)

```html
<a href="index.html" class="prototype-nav-pill">← All Pages</a>
```

For RTL pages: `href="index.html"` label `جميع الصفحات ←`, positioned `left: 20px`.

CSS:
```css
.prototype-nav-pill {
  position: fixed; bottom: 20px; right: 20px;
  background: rgba(0,0,0,0.75); color: #fff;
  padding: 8px 16px; border-radius: 999px;
  font-size: 13px; font-family: sans-serif;
  text-decoration: none; z-index: 9999;
  backdrop-filter: blur(4px);
  transition: background 0.2s;
}
.prototype-nav-pill:hover { background: rgba(0,0,0,0.9); }
```
